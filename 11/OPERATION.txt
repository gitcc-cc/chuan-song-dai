========================================
ESP32-S3 传送带控制固件 使用说明
========================================

【硬件接线】
----------------------------------------
GPIO  功能              备注
4     按钮              内部上拉，按下=LOW
7     电位器 ADC        0~3.3V -> 速度 0~13
18    电机 A            传送带电机驱动
15    电机 B            传送带电机驱动
5     光纤传感器        NPN: LOW=检测到物体, HIGH=无物体
16    舵机串口 RX       接舵机 TX
17    舵机串口 TX       接舵机 RX
48    板载 RGB LED      NeoPixel, 1颗
---   舵机供电          必须共地，独立供电(勿从ESP32 5V取)
---   USB转TTL          接 GPIO43(TX)/GPIO44(RX)/GND 用于烧录和串口监视

【固件构建与烧录】
----------------------------------------
cd 11

# 串口烧录(默认环境)
pio run -e esp32s3-usb -t upload

# OTA 无线烧录(需先配置 platformio.ini upload_port 为板子实际IP)
pio run -e esp32s3-ota -t upload

# 串口监视器(波特率 115200)
pio device monitor

【串口说明】
----------------------------------------
- 当前配置: Serial -> UART0 (GPIO43/44, TTL口)
- OTG口(USB-C) 未启用 USB CDC，仅供将来 HID/MSC/CDC 设备功能扩展
- 烧录、监视、调试均走 TTL 口，打开监视器会复位板子(正常)

【本地操作(无需网络)】
----------------------------------------
按钮(短按): 状态循环  停止(0) -> 正转(1) -> 反转(2) -> 自动(3) -> 停止...
电位器:     就地模式下实时调速 0~13
自动模式:   传感器LOW(有物体)->停, HIGH(无物体)->正转(电位器速度)
RGB指示:    自动模式下 蓝=检测到物体/延时中, 白=正转中

【MQTT 远程控制】
----------------------------------------
Broker:     10.107.243.56:1883 (myMqtt.h 硬编码)
ClientID:   esp32_conveyor
命令主题:   ht/cmd/1
状态主题:   ht/status/1 (保留消息)

支持命令:
  status            查询状态, 返回 JSON
  dj 0/1/2/3        状态切换: 停止/正转/反转/自动
  speed 0~13        远程调速(仅远程模式生效)
  mode local        切换到就地模式(电位器控速)
  mode remote       切换到远程模式(滑块控速)
  en 0              解抱闸(扭矩关闭)
  en 1              上抱闸(扭矩开启, 切轮模式)
  hello             测试通信

状态 JSON 格式:
  {"state":0-3,"speed":0-13,"pot":0-100,"sensor":0/1,"mode":0/1}
  state: 0停 1正 2反 3自
  speed: 当前实际舵机速度
  pot:   电位器百分比
  sensor:传感器电平(0=有物体)
  mode:  0就地 1远程

【网络连接行为】
----------------------------------------
1. 上电 -> 发起 WiFi 连接(非阻塞)
2. WiFi 连上 -> 连接 MQTT Broker(阻塞≤2秒, 失败不重试)
3. 后续掉线 -> 不自动重连, 本地控制完全不受影响
   (需人工复位或 OTA 烧录恢复网络功能)
4. 设计取舍: 保证按钮/传感器/电机实时响应零延迟

【OTA 无线烧录】
----------------------------------------
- WiFi 连上后自动启动 ArduinoOTA 服务
- 主机名: ESP32-S3
- 密码:   1234 (ota.h 已设置)
- PlatformIO OTA 环境: pio run -e esp32s3-ota -t upload
- 串口监视会打印 OTA 进度和 IP

【舵机速度寄存器(地址46)】
----------------------------------------
0       = 停止
1~13    = 反转(慢->快)
128~141 = 正转(慢->快)  (128+speed)

【常见问题】
----------------------------------------
1. 串口无输出: 确认 TTL 模块接线(TX<->RX)、波特率115200、已烧录最新固件
2. 舵机不动:  检查舵机供电、共地、ID是否为6、串口波特率1Mbps
3. 网络不通:  检查 WiFi 名/密、Broker IP/端口、防火墙、串口日志报错
4. 自动模式不停: 确认传感器 NPN/LOW 有效、接线正确、GPIO5 未被占用
5. 速度不生效: 确认当前模式(就地/远程)、speed 范围 0~13
