【V3.0】架构重构：PC 为中心的多设备协同控制

  架构变更：
  - 当前架构：ESP32(TCP 服务器) ← 电脑(TCP 客户端)
  - 目标架构：电脑(TCP 服务器/主控) ← 多设备(TCP 客户端)

  目标设备：
  - ESP32-S3 传送带控制板（已有）
  - 机械臂（待接入）
  - 机械狗（待接入）
  - 人形机器人（待接入）

  核心功能：工业时序控制
  - 电脑作为主控中心，编排和调度所有设备的动作时序
  - 支持时序流程编辑：定义设备动作的先后顺序、延时、条件触发
  - 流程示例：传送带正转 → 光纤传感器检测到位 → 传送带停止 → 机械臂抓取 →
             机械臂放料 → 传送带继续 → 机械狗搬运 → 人形机器人接收
  - 每个设备独立状态面板，实时显示各自状态
  - 支持手动单控和自动流程两种模式
  - 流程执行中可暂停、恢复、跳步
  - 异常处理：设备超时未响应、动作失败时自动停机并报警

  技术要点：
  - 上位机改为多线程 TCP 服务器，每个客户端独立线程处理
  - 协议增加设备 ID 字段，区分不同设备的命令和状态
  - 时序引擎：基于状态机或 Petri 网的流程调度器
  - ESP32 固件改为 TCP 客户端，开机自动连接电脑服务器
  - 界面左侧增加设备列表 + 流程状态面板，右侧为选中设备的控制区

  状态：未完成

【V3.1】智能仓储系统流程（草案，待确认）

  3.1 入库流程

  1. 振动盘送料，物块到达传送带
  2. 机械臂夹取物块，扫描二维码获取 item_id
  3. 机械臂将物块放入暂存区
  4. 人形机器人从暂存区取物块
  5. 人形机器人查询数据库：
     - 该 item_id 是否已绑定用户？
     - 如果有绑定，获取用户绑定的物块坐标（可能为空）
  6. 人形机器人决定放置位置：
     - 如果用户已有绑定物块且坐标存在 → 放到指定坐标（替换旧物块）
     - 如果用户无绑定物块 → 分配空闲坐标（如第一个空格）
     - 如果用户已有绑定物块但坐标不存在 → 分配新坐标
  7. 人形机器人放置物块到指定坐标
  8. 更新数据库：
     - 物块状态设为 'in_stock'
     - 记录 shelf_x, shelf_y, shelf_z
     - 建立或更新绑定关系
  9. 同步信息给人形机器人（通过 MQTT 或数据库轮询）

  3.2 出库流程（固定绑定）

  1. 用户在身份终端验证身份，获取 user_id
  2. 系统查询绑定表：SELECT item_id FROM bindings WHERE user_id = ?
  3. 如果无绑定，提示"无绑定物块"，结束
  4. 如果有绑定，查询物块状态：
     - 如果 status != 'in_stock'，提示"物块不可用"，结束
  5. 系统锁定物块：UPDATE items SET status = 'locked' WHERE item_id = ?
  6. 系统发送取货指令给人形机器人：
     - 指令包含：item_id, shelf_x, shelf_y, shelf_z, target_x, target_y, target_z（取货坐标）
  7. 人形机器人执行：
     a. 移动到货架坐标 (shelf_x, shelf_y, shelf_z)
     b. 抓取物块
     c. 移动到取货盘坐标
     d. 放置物块
  8. 更新数据库：
     - 物块状态设为 'shipped'
     - 清空物块的位置坐标
     - 可选：解除绑定关系（或保留以备下次存放）
  9. 通知用户取货（语音/屏幕）
  10. 记录操作日志

  状态：未完成
